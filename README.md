# Formulário de Venda de Imóvel 🏠📄  
Um projeto em HTML e CSS criado para facilitar o cadastro e envio de informações de imóveis à venda.  
O objetivo é oferecer um formulário responsivo, organizado e agradável para o usuário preencher.

## 📌 Sobre o Projeto
O site apresenta um formulário completo para cadastrar um imóvel, incluindo:
- Título do anúncio  
- Preço  
- Endereço completo  
- Número de cômodos  
- Descrição detalhada  
- Estado de conservação  
- Data de aquisição  
- Tipo de imóvel  
- Opcionais (piscina, quintal, garagem etc.)  
- Upload de fotos  

Tudo isso dentro de um layout limpo, moderno e responsivo.

## 🛠️ Tecnologias Utilizadas
- **HTML5**  
- **CSS3**  
- Responsividade com Media Queries
